Why a realm with no other players

WotLK private servers usually solve loneliness by growing a community. This one solves it by never needing one. Every character you'll ever party with, buy from, or watch stroll past in Dalaran is a bot — mod-playerbots running its own AI, not a scripted NPC standing in one spot.

They level on their own schedule, form and leave guilds, list items on the Auction House, and — with an LLM wired in — actually talk, instead of cycling four canned lines. Recruit any of them into your party like a real person would join you, or just let the world happen around you.

The result isn't a multiplayer server pretending to be full. It's a single-player RPG that happens to run on an MMO's engine.

Ten modules, one worldserver
mod-playerbotsThe AI companions themselves — questing, leveling, grouping, guilding, all on their own.
mod-llm-chatterBots chat through a real LLM (Claude, GPT, Gemini, or a local Ollama model) instead of canned lines.
mod-solocraftScales dungeon and raid stats to your actual group size, so a duo of bots can clear what needed a raid.
mod-ah-botKeeps the Auction House stocked and bidding, so the economy isn't just an empty menu.
mod-individual-progressionGates content by era — Vanilla, then TBC, then WotLK — on the same client, in original release order.
mod-cfbgCross-faction battlegrounds, so the fixed bot population can actually fill a PvP queue.
mod-npc-bufferA one-click buff station — no begging strangers for a blessing that isn't coming.
mod-account-achievementsShares achievement progress across every character on your account.
mod-instance-resetReset your own dungeon and raid lockouts on demand, instead of waiting out the timer.
mod-random-enchantsA tuned-down chance of a bonus enchant on loot, so drops occasionally feel special.
Built to disappear when you're not using it

This runs on a fanless mini PC, not a rented data-center box — an Intel NUC with two physical cores, Turbo Boost permanently disabled because the package sits at 85–88°C even without it. A hundred bots ticking AI logic around the clock isn't something that hardware can just absorb for free.

So it doesn't run around the clock. A proxy holds the real connection ports open at all times and does nothing else — the moment a client tries to log in, if the game stack is asleep, it wakes everything, holds the connection open through the ~60–70 second cold boot, then gets out of the way. Five minutes after the last real player disconnects, the whole stack backs itself up and stops. No idle heat, no fan noise, no cost for a world nobody's currently watching.

A dashboard that admits what it doesn't know

A live status page tracks the realm even while it sleeps — population, guild rosters, top crafters by profession, the auction house, and the host's own CPU and temperature. It's built to stay honest: a section that turned out to be structurally incapable of showing real data got removed rather than left there looking broken.

Running it yourself

No build toolchain needed — the core and all ten modules ship as prebuilt Docker images. Clone the repo, run one script, connect a 3.3.5a client.

$ git clone https://github.com/estebanmorenoit/wow-server-playerbots.git
$ cd wow-server-playerbots
$ ./deploy.sh
